Fluent Mesh Study Automation Script (PyFluent-based)
=====================================================

This Python script automates the process of performing mesh sensitivity studies in ANSYS Fluent using the PyFluent API. It reads mesh files, applies boundary conditions, initializes the solution, performs a short run, and saves key outputs.

-----------------------------------------------------
Directory Structure
-----------------------------------------------------

📂 your_project_directory/
├── mesh1.msh
├── mesh2.msh
├── automationScript.py
└── simulation_log.txt  ← log file generated by the script

After execution, a new folder will be created for each mesh:
📂 mesh1_20250424_143000/
├── mesh1.dat.h5
├── pressure_drop.txt
├── velocityXY.xy
└── mesh1.cas.h5

-----------------------------------------------------
Script Features
-----------------------------------------------------

- Batch processes all `.msh` files in the script's directory.
- Automatically sets up boundary conditions:
  - Velocity inlet
  - Pressure outlet
  - No-slip stationary wall
- Uses hybrid initialization with user-defined iteration count.
- Runs a short number of solver iterations.
- Captures:
  - Pressure drop between inlet and outlet
  - Velocity profile along centerline
  - Fluent's mesh quality report (via console output capture)
- Saves case and data file.
- Logs events and durations for each case in simulation_log.txt.

-----------------------------------------------------
How to Use
-----------------------------------------------------

Requirements:
- ANSYS Fluent 24.2 or compatible
- PyFluent installed (via ansys.fluent.core)
- Python 3.8+

Steps:
1. Place all your `.msh` mesh files in the same folder as the script.
2. Optionally edit the simulation parameters at the top of the script:
   INLET_VELOCITY = 1.0
   INIT_ITERATIONS = 10
   CALCULATION_ITERATIONS = 8
3. Run the script using:
   python mesh_study_script.py
(Note: I executed it with - exec(open("automationScriptTemplate.py").read()) command inside the python console in Fluent (beta).
4. Output will be saved in a timestamped folder for each mesh.

-----------------------------------------------------
Script Output
-----------------------------------------------------

For each mesh, the script creates:
- pressure_drop.txt: Area-averaged pressure difference (inlet - outlet).
- velocityXY: Plot file of velocity magnitude along a vertical line.
- .cas.h5: Case and data file saved after computation.

Also:
- simulation_log.txt records all key actions, timestamps, and durations.

-----------------------------------------------------
Customization
-----------------------------------------------------

- Boundary condition zones must be named:
  - `inlet`, `outlet`, `particle_bed`
- You can change the coordinates for line-surface creation for other probe lines.
